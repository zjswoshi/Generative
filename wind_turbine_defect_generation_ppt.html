Step 02

统一 LoRA 训练框架

两种训练范式

单阶段训练

仅学习缺陷 Patch 纹理，适用于 img2img 局部替换

patches → 缺陷纹理 LoRA

两阶段训练

先学叶片外观，再学缺陷特征，适用于 txt2img 完整生成

full_images → patches → 叶片+缺陷 LoRA 
# 自动检测模式（推荐）
python train_lora_unified.py \
  --data-dir ./hq_output \
  --mode auto

# 单阶段训练
python train_lora_unified.py \
  --mode single

# 两阶段训练
python train_lora_unified.py \
  --mode two-stage \
  --stage1-steps 2000 \
  --stage2-steps 3000

训练参数建议

阶段 分辨率 学习率 步数 目标
Stage 1 512×512 1e-4 1500-2000 学习叶片外观
Stage 2 256×256 5e-5 2000-3000 学习缺陷特征（防遗忘）
单阶段 256×256 1e-4 2000-3000 学习缺陷纹理

Step 03

4 种缺陷生成模式

txt2img + SD

纯文本生成，快速大批量，速度优先

文字 → 完整图像

txt2img + AnomalyAny

CLIP 引导，文本-图像一致性更好

文字+LoRA → 精确图像

img2img + SD

局部替换，保持背景，只改 mask 区域

图像+Mask → 编辑后图像

img2img + AnomalyAny

CLIP 引导 + 局部替换，最高质量控制

图像+Mask+LoRA → 精准编辑 
# txt2img + AnomalyAny（推荐）
python generate_defects.py \
  --mode txt2img \
  --pipe anomalyany \
  --prompt "wind turbine blade with paint peeling" \
  --lora-path ./outputs/lora_unified/two_stage/stage2/final
# img2img + SD（局部替换）
python generate_defects.py \
  --mode img2img \
  --pipe sd \
  --image normal_blade.png \
  --mask defect_mask.png \
  --lora-path ./outputs/lora_unified/single/final

YOLOv11-seg 实例分割

为什么选择分割？

  • 像素级定位

    不仅仅是检测缺陷位置，还能精确到像素级边界

  • 实例区分

    区分同一图像中的多个缺陷实例

  • 增强数据

    用生成的缺陷样本大幅扩充训练集

# 训练配置
model = YOLO("yolo11n-seg.pt")

results = model.train(
    data="dataset.yaml",
    epochs=150,
    imgsz=640,
    batch=16,
    optimizer="SGD",
    lr0=0.01,
    mosaic=1.0,
    mixup=0.2,
    copy_paste=0.1,
    close_mosaic=20,
    amp=True,
)

Innovation

核心创新点

VLM 驱动的数据增强

首次将 VLM（qwen3.5:27b）引入风机叶片缺陷数据集构建，实现自动化的结构化描述生成，解决传统方法依赖人工标注的瓶颈。

统一 LoRA 训练框架

将单阶段和两阶段训练统一为单一入口，支持自动检测数据源选择最佳训练模式，大幅降低使用门槛。

4 种生成模式矩阵

txt2img/img2img × SD/AnomalyAny 组合，覆盖从快速批量生成到精确局部控制的全部场景需求。

端到端闭环系统

从缺陷生成到检测训练形成完整闭环，生成数据直接用于训练 YOLOv11-seg，实现像素级缺陷检测。
