AnomalyAny 详解：三大损失函数

损失函数详解

L_att：注意力损失

目标：

让缺陷关键词获得足够高的注意力

loss_att = max(0, 1 - target_attention)

L_img：CLIP损失

目标：

让生成的图片与文本在CLIP空间更接近

后期（t > 70% 才开启

L_prompt：文本嵌入优化

让简短提示词嵌入向详细提示词嵌入靠拢

优化同时优化latent和文本embedding

AnomalyAny 核心：_update_latent 函数

梯度下降更新latent

@staticmethod

def _update_latent(latents, loss, step_size, return_grad=False):

# 计算损失对latent的梯度

grad_cond = torch.autograd.grad(

loss.requires_grad_(True),

[latents],

retain_graph=True

)[0]

# 梯度下降更新

latents = latents - step_size * grad_cond

return latents

关键点

为什么有效但有上限？

  • latent是可训练变量！但只是优化临时改变
  • retain_graph=True，保留计算图
  • 但模型本身没见过的东西，优化也创造不出来！

核心结论：模型上限问题

维度 LoRA AnomalyAny
本质 训练（改变权重） 测试时优化
数据需求 10-100张图 0张（仅文本）
知识来源 训练样本教给模型 完全依赖预训练

结论

LoRA与AnomalyAny只是锦上添花

生成效果的上限完全取决于基础模型！
