Inpainting Pipeline详解（2/2）

完整流程

步骤1：输入图像 + Mask（白色=需要重绘，黑色=保留）
步骤2：原图通过VAE编码 → latent_source
步骤3：初始化latent（随机噪声或img2img方式）
步骤4：去噪循环：
  • a) UNet预测噪声
  • b) CFG引导
  • c) Scheduler更新 → denoised_latent
  • d) 给latent_source加同样t步噪声 → noised_source
  • e) 混合：latent = denoised_latent * mask + noised_source * (1-mask)
步骤5：VAE解码 → 最终图像
关键优势：只修改Mask区域，其余部分完美保留，且边界自然过渡

AnomalyAny三大损失函数详解（1/2）

L_att：注意力损失

目标

让缺陷关键词（如"scratch"）获得足够高的注意力

# 伪代码
attn_map = get_attention_map(UNet)
target_attn = attn_map[target_token_indices]
# 最大化每个目标token的空间最大注意力
loss_att = max(0, 1 - max(target_attn))

L_img：CLIP损失（后期）

目标

让生成图像在CLIP空间更接近文本描述

# 后期开启（t>70%）
decoded_img = VAE.decode(latent)
img_emb = CLIP.encode_image(decoded_img)
txt_emb = CLIP.encode_text(prompt)
loss_img = 1 - cosine_similarity(img_emb, txt_emb)
为什么L_img后期才开启？：早期图像太模糊，CLIP指导效果不好；后期图像结构形成后再用CLIP精修细节

AnomalyAny三大损失函数详解（2/2）

L_prompt：文本嵌入优化损失

最终总损失：loss_total = 0.1 * loss_img + 0.5 * (t/T) * loss_att

loss_att权重随步数增加，后期更强调注意力

核心函数：_update_latent 详解

梯度下降更新latent

@staticmethod

def _update_latent(latents, loss, step_size, return_grad=False):

# 计算损失对latent的梯度

grad_cond = torch.autograd.grad(

loss.requires_grad_(True),

[latents],

retain_graph=True

)[0]

# 梯度下降更新

latents = latents - step_size * grad_cond

return latents

关键要点

要点说明
requires_gradlatent是可训练变量！但只在优化步临时改变
retain_graph保留计算图，后续步骤可继续使用
step_size学习率，控制每次更新的步长
核心创新：完全在latent空间操作，不改变SD预训练权重！

核心结论：模型上限问题

方面 LoRA AnomalyAny
本质 训练（改变模型权重） 测试时优化（不改权重）
数据需求 10-100张训练图像 0张（仅文本）

能力边界 可以突破基础模型的限制 上限就是基础模型的能力天花板

重要结论

LoRA和AnomalyAny都只是锦上添花！

它们的上限完全由基础模型的能力决定！
