3 / 16
SD 整体架构

三大核心组件

  • Text Encoder: CLIP ViT-L/14，将文本转为 embedding
  • UNet: 条件去噪网络，注入文本条件
  • VAE: 图像编码/解码到 latent 空间
关键问题：UNet 学到的能力由训练数据决定！
4 / 16
Text-to-Image 流程

完整步骤

  1. 文本 → CLIP → Text Embedding
  2. 随机噪声初始化
  3. 去噪循环：UNet 预测噪声 + CFG + Scheduler 更新
  4. Clean Latent → VAE → 最终图片

CFG

noise_pred = noise_pred_uncond + guidance_scale × (noise_pred_text - noise_pred_uncond)
5 / 16
Img2Img 与 Inpainting

Img2Img 核心

先加噪，再去噪，由 denoising_strength 控制加噪程度

Inpainting: Masked Noise Blending

  • 保留原图非 mask 区域
  • 两边同步加噪，边界更平滑
  • 混合：去噪结果 × mask + 原图加噪 × (1-mask)

7 / 16
AnomalyAny 优化机制

三大损失函数

  • L_att: 注意力损失，让关键词被关注
  • L_img: CLIP 损失，后期开启
  • L_prompt: 文本嵌入损失，对齐详细描述

核心创新

  • latents 变为可训练变量
  • 梯度下降优化
  • 完全在 latent 空间，不破坏 SD

核心结论：模型上限问题
方面 LoRA AnomalyAny
本质 训练（改变权重） 测试时优化
数据需求 10-100 张 0 张（纯文本）
