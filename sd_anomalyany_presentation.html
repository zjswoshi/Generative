Text-to-Image (Text2Img)

Core Components

Component Function

VAE Compresses images to 8x smaller latent space
UNet Predicts and removes noise from latents
Scheduler Controls denoising process (Euler, DPM++, etc.)

Text-to-Image (Text2Img)

Code Perspective

# Pseudo-code for Text2Img
def text2img(prompt, negative_prompt, 
             num_inference_steps=50, 
             guidance_scale=7.5):
    
    # 1. Encode text
    prompt_embeds = text_encoder(prompt)
    negative_embeds = text_encoder(negative_prompt)
    
    # 2. Initialize random latents
    latents = torch.randn(batch_size, 4, height//8, width//8)
    latents = latents * scheduler.init_noise_sigma
    
    # 3. Denoising loop
    for t in scheduler.timesteps:
        # Expand latents for CFG
        latent_model_input = torch.cat([latents] * 2)
        
        # UNet prediction
        noise_pred = unet(latent_model_input, t, 
                         encoder_hidden_states=prompt_embeds)
        
        # CFG
        noise_pred_uncond, noise_pred_text = noise_pred.chunk(2)
        noise_pred = noise_pred_uncond + guidance_scale * (
                     noise_pred_text - noise_pred_uncond)
        
        # Scheduler update
        latents = scheduler.step(noise_pred, t, latents).prev_sample
    
    # 4. Decode to image
    image = vae.decode(latents).sample
    return image

Classifier-Free Guidance (CFG)

The Secret Sauce

CFG Formula:
noise_pred = noise_pred_uncond 
          + guidance_scale * (noise_pred_text - noise_pred_uncond)


Parameters:
┌──────────────────────────────────────────────────┐
│ guidance_scale = 1   → Almost random             │
│ guidance_scale = 5   → Somewhat follows prompt   │
│ guidance_scale = 7.5 → Default, balanced         │
│ guidance_scale = 15  → Very strict, may overfit │
└──────────────────────────────────────────────────┘

Image-to-Image (Img2Img)

Denoising Strength

Denoising Strength Effect
0.0 Output = Input (no change)
0.3 Very similar to input, minor modifications
0.5 Moderate changes, preserves structure
0.75 Major changes, some structure preserved
1.0 Complete re-generation (like text2img)

Image-to-Image (Img2Img)

Code Perspective

def img2img(init_image, prompt, denoising_strength=0.75):
    
    # 1. Encode initial image
    init_latent = vae.encode(init_image).latent_dist.sample()
    
    # 2. Calculate start timestep
    t_start = int(num_inference_steps * (1 - denoising_strength))
    
    # 3. Add noise to initial latent
    noise = torch.randn_like(init_latent)
    latents = scheduler.add_noise(init_latent, noise, 
                                  timesteps=[t_start])
    
    # 4. Encode text
    prompt_embeds = text_encoder(prompt)
    
    # 5. Denoising loop (from t_start to 0)
    for t in scheduler.timesteps[t_start:]:
        # Same as text2img denoising
        noise_pred = unet(latents, t, prompt_embeds)
        noise_pred = apply_cfg(noise_pred, guidance_scale)
        latents = scheduler.step(noise_pred, t, latents).prev_sample
    
    # 6. Decode
    image = vae.decode(latents).sample
    return image

        image_curr = decode_latents_new(latents)

                                   loss_prompt, 0.002)

AnomalyAny Pipeline

Latent Update Mechanism

# Line 732-791 in clip_pipeline_attend_and_excite.py
@staticmethod
def _update_latent(latents, loss, step_size):
    # Compute gradient of loss w.r.t. latents
    grad = torch.autograd.grad(
        loss.requires_grad_(True),
        [latents],
        retain_graph=True
    )[0]
    
    # Gradient descent!
    # latents_new = latents_old - step_size * gradient
    latents = latents - step_size * grad
    
    return latents


# We're treating latents as a "parameter" to optimize!
# Loss tells us what direction to move latents in to
# better match the text/attention!

Summary

Key Takeaways

  • Text2Img: From random noise to image guided by text
  • Img2Img: Start from existing image, add noise, denoise
  • Inpainting: Only modify mask region via masked blending
  • AnomalyAny: Hooks into SD's denoising loop, adds inner optimization for better text/defect alignment
