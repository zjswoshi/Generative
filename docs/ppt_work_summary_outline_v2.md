## Slide 5: Text-to-Image Pipeline（图示）
### 文字生图流程
```
时间步 t=50 ──────→ t=0
  │                  │
噪声 ──────────→ 干净图片
  │
  │ 每步:
  │  1. UNet 预测噪声
  │  2. CFG 应用
  │  3. Scheduler 更新
```

### CFG 原理（公式示意）
```
noise_pred = noise_pred_uncond + guidance_scale × (noise_pred_text - noise_pred_uncond)
```

## Slide 6: Img2Img 与 Inpainting（图示）
### Image-to-Image
```
原图 ──→ VAE ──→ 加噪 ──→ 去噪 ──→ VAE ──→ 结果
                ↑
         denoising_strength
```

### Inpainting 核心：Masked Blending
```
每去噪步:
┌─────────────────────────────────────────┐
│ Latents（去噪中） × Mask             │
│                        +                │
│ Latents_source（原图）× (1-Mask) ← 同步加噪 │
└─────────────────────────────────────────┘
              ↓
         混合结果
```

**为什么同步加噪？** → 边界更平滑！

## Slide 9: 核心结论（1/2）：模型上限
### LoRA vs AnomalyAny
| 方面 | LoRA | AnomalyAny |
|------|------|------------|
| 本质 | 训练（改变权重） | 测试时优化 |
| 数据 | 10-100张 | 0张 |
| 上限 | 有限 | **完全依赖基础模型** |

### 图示化结论
```
┌─────────────────────────────────────────────┐
│ LoRA 和 AnomalyAny 只是「锦上添花」！  │
│                                               │
│ 它们的上限 = 基础模型的能力上限          │
└─────────────────────────────────────────────┘
```

## Slide 10: 核心结论（2/2）：SD2.1 的问题
### 为什么 SD2.1 总是动漫风？
```
┌─────────────────────────────────────────────┐
│ 训练数据 LAION 中动漫/插画占比高         │
│                                              │
│ 模型学到了这个分布 → 生成总是有动漫风 │
└─────────────────────────────────────────────┘
```

### 对比：真实感 vs 动漫风格
| 特征 | SD2.1 | 真实感模型 |
|------|-------|----------|
| 人脸 | 动漫化 | 真实 |
| 色彩 | 饱和 | 自然 |
| 结构 | 简化 | 准确 |

## Slide 11: 模型对比实验（图示化）
### 实验设置
- **相同**：text-to-image，无 LoRA/AnomalyAny
- **变量**：不同基础模型
- **prompt**：「a person using a phone, realistic photo」

### 结果对比
```
SD2.1       ⭐    （高动漫风）
Realistic Vision 1.5 ⭐⭐⭐⭐⭐ （低动漫风，真实感强）
SDXL        ⭐⭐⭐⭐ （中等）
ZImage      ⭐⭐⭐⭐⭐ （低动漫风，真实感强）
```

### 结论
- **SD2.1 确实不适合真实感任务**
- **换用更好的基础模型是关键**！
