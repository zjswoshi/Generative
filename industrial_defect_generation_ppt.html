Step 02

LoRA 微调模块

两种训练范式

单阶段训练

仅学习缺陷 Patch 纹理，适用于 img2img 局部替换

patches → 缺陷纹理 LoRA

两阶段训练

先学正常外观，再学缺陷特征，适用于 txt2img 完整生成

normal → defect → 完整外观 + 缺陷 LoRA 
# 自动检测模式（推荐）
python train_lora_unified.py \
  --data-dir ./hq_output \
  --mode auto

# 单阶段训练（img2img 用）
python train_lora_unified.py \
  --mode single

# 两阶段训练（txt2img 用）
python train_lora_unified.py \
  --mode two-stage \
  --stage1-steps 2000 \
  --stage2-steps 3000

训练参数建议

模式 分辨率 学习率 步数 适用场景
Stage 1（两阶段） 512×512 1e-4 1500-2000 学习正常样本外观
Stage 2（两阶段） 256×256 5e-5 2000-3000 学习缺陷特征（防遗忘）
单阶段 256×256 1e-4 2000-3000 仅学缺陷纹理

Step 03

缺陷生成模块（4 种模式）

灵活应对不同工业场景的生成需求

txt2img SD

纯文本生成

仅通过文本描述直接生成缺陷图像。速度快，适合大批量快速生成。

文字 → 图像
txt2img AnomalyAny

CLIP 引导生成

利用 CLIP 损失引导生成，文本-图像一致性更好，质量更高。

文字 + LoRA → 精确图像
img2img SD

局部替换

在原始图像的指定区域生成缺陷，保持背景和其余部分不变。

图像 + Mask → 编辑后图像
img2img AnomalyAny

精准编辑

CLIP 引导 + 局部替换，在指定区域生成高质量缺陷，最精确控制。

图像 + Mask + LoRA → 精准编辑 
# txt2img + AnomalyAny（推荐）
python generate_defects.py \
  --mode txt2img \
  --pipe anomalyany \
  --prompt "metal surface with scratch damage" \
  --lora-path ./outputs/xxx/final
# img2img + SD（局部替换）
python generate_defects.py \
  --mode img2img \
  --pipe sd \
  --image normal_product.png \
  --mask defect_mask.png \
  --lora-path ./outputs/xxx/final

Features

核心特性

VLM 智能标注

自动生成结构化描述，无需人工撰写 Caption，大幅提升数据准备效率。

灵活生成模式

4 种模式矩阵（txt2img/img2img × SD/AnomalyAny），覆盖从快速批生成到精准编辑的全部需求。

类别均衡支持

自动诊断类别分布，针对性生成少数类样本，解决数据不均衡问题。

统一训练框架

单入口支持单阶段/两阶段/自动模式，自动检测数据源选择最佳训练策略。

端到端闭环

从缺陷生成到检测训练形成完整闭环，生成数据直接用于训练实例分割模型。

模块化解耦

数据准备、LoRA 训练、缺陷生成、检测训练均可独立使用，灵活组合。
